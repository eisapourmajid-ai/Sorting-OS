# گزارش‌های شواهد عامل کدنویس

گزارش‌های تولیدشده توسط عامل باید اینجا قرار بگیرند. گزارش‌ها نباید رمز، token، داده واقعی بانک، نام/شماره شناسایی مشتری، یا فایل پایگاه داده عملیاتی را شامل شوند. هر گزارش به commit SHA و دستورات واقعی build/test متصل باشد. گزارش فقط بعد از بررسی مالک/مهندس responsible می‌تواند PASS شود.

- `INITIAL_REPOSITORY_AUDIT.md`: خروجی Prompt 00 برای مخزن واقعی.
- `BASELINE.md`: خروجی Prompt 01 با فرمان و نتیجه تکرارپذیر.
- `EXECUTION_LEDGER.md`: یک رکورد به‌ازای هر prompt اجراشده.
