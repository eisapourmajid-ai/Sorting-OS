## ۱) دستور

> «درصد صافی ها باید قابل تخصیص برای هر حساب فرشنده یا فاکتور لحاظ شود. یعنی ممکنه صافی هر
> فاکتور متفاوت باشد و باید قابلیت اینکه پیش فرض داشته باشد و اینکه ویرایش شود وجود داشته باشد.»

## ۲) چه چیزی پیاده‌سازی شد

| قابلیت | پیاده‌سازی |
|---|---|
| نرخ پیش‌فرض (قابل ویرایش) | `SettlementService.set_default_rate()` — جدول `settlement_rates` با scope=`default` |
| نرخ هر حساب طرف/فرشنده | `set_party_rate(party_id, …)` — scope=`party` |
| نرخ هر فاکتور | `set_invoice_rate(invoice_id, …)` — scope=`invoice` |
| ترتیب اعمال | `invoice ← party ← default` (ورود دستی در لحظهٔ محاسبه بالاتر از همه) |
| ویرایش | نسخهٔ قبلی بسته می‌شود (`valid_to` + `is_active=0`) و نسخهٔ جدید ثبت می‌شود ⇒ سابقه حفظ، گذشته بازنویسی نمی‌شود |
| بازخوانی نرخ مؤثر | `resolve_rate(party_id, invoice_id, on_date)` |
| حذف نرخ | `deactivate_rate(rate_id)` ⇒ سطح بعدی اعمال می‌شود |
| ثبت منشأ نرخ | ستون‌های `settlements.rate_source` و `settlements.rate_id` + `payload_json` |
| چاپ | `print_payload()` نرخ و منشأ آن را در صورتحساب صافی نشان می‌دهد |
| صفحهٔ اپراتور | تب «صافی و درصد» در پوسته: ثبت نرخ پیش‌فرض/طرف/فاکتور، نمایش نرخ مؤثر، تاریخچهٔ نرخ‌ها |
| بدون نرخ | محاسبه با پیام روشن رد می‌شود (فرض درصد ممنوع است) |

## ۳) فایل‌های تغییرکرده

- `desktop/sorting_os/migrations.py` — `MIGRATION_3` (تراکنشی و نسخه‌دار): جدول `settlement_rates`
  با قید سطح/هدف، ایندکس یکتای هدف و سه ستون جدید روی `settlements`
  (`invoice_id`, `rate_source`, `rate_id`). `LATEST_SCHEMA_VERSION` = ۳.
- `desktop/sorting_os/services/settlement.py` — API تخصیص نرخ، `resolve_rate`، اعمال نرخ در
  `calculate` (به‌همراه پارامتر تازهٔ `invoice_id`)، `print_payload`، به‌روزرسانی یادداشت سند posting.
- `desktop/sorting_os/services/printing.py` — قالب پیش‌فرض صورتحساب صافی فیلد `rate_display` گرفت؛

  قالب‌های سفارشی اپراتور).
- `desktop/sorting_os/app.py` — همگام‌سازی قالب‌ها هنگام شروع (`--init-db` و اجرای GUI).
- `desktop/sorting_os/ui/app.py` — تب «صافی و درصد» (ثبت/ویرایش نرخ، نرخ مؤثر، تاریخچه).
- `desktop/tests/test_settlement_rates.py` — ۱۸ آزمون جدید.
- `desktop/tests/test_migrations.py` — آزمون جدید ستون‌ها و جدول نسخهٔ ۳.
