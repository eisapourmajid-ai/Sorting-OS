# فهرست بسته و راهنمای اعمال patch

## بسته اجرایی
- `MASTER_PROMPT.md`: دستور مادر
- `README_START_HERE_FA.md`: راهنمای اجرای ترتیب فازها
- `prompts/00` تا `prompts/26`: 27 پرامپت مستقل
- `SORTING_OS_ALL_PROMPTS_COMBINED_FA.md`: نسخه تجمیعی برای مطالعه/کپی
- `EXECUTION_LEDGER.md`: دفتر وضعیت و شواهد
- `repo-patch/`: اسناد آماده انتقال به مخزن
- `reference-inputs/`: اسناد ورودی استفاده‌شده برای هم‌راستاسازی بسته

## قرارداد patch
این patch عمدتاً مستندات و الگوی مشارکت را تغییر می‌دهد؛ شامل پیاده‌سازی سورس برنامه نیست. فایل‌های `README.md`، issue templates و PR template در پوشه `repo-patch` نسخه‌های بازنویسی‌شده‌اند؛ پیش از جایگزینی، diff را با مخزن اصلی مرور کنید. اگر README اصلی محتوای ویژه دارد، موارد لازم را merge کنید نه اینکه بی‌بررسی حذف کنید.

## مسیرهای هدف پیشنهادی
- `repo-patch/README.md` → `README.md`
- `repo-patch/docs/10-master-ai-coding-directive.md` → `docs/10-master-ai-coding-directive.md`
- سایر فایل‌های `repo-patch/docs/*` → همان مسیر زیر `docs/`
- `repo-patch/.github/*` → همان مسیر زیر `.github/`
- سایر docs پایه در patch هم کپی شده‌اند تا یک نمای کامل بسازند؛ آنها را همگی کورکورانه overwrite نکنید. از diff و نسخه فعلی استفاده کنید.

## تناقض‌های مهم که عمداً پنهان نشده‌اند
- پشته نهایی، نسخه کتابخانه‌ها و معماری اجرا باید از سورس واقعی و گیت سازگاری مشخص شود.
- مدل تجاری (خرید مستقیم/خدمت سورتینگ/ترکیبی)، فرمول صافی، پایه درصد و برخی قواعد حسابداری نیازمند تصمیم صاحب کسب‌وکار است.
- تک‌رایانه یا استفاده همزمان چندکاربره باید تعیین شود؛ استفاده چند کلاینت از SQLite روی share فایل نباید پیش‌فرض شود.
- Windows 7 SP1 x64 هدف درخواستی است اما تا تست واقعی تأیید نشده.
- هیچ سورس برنامه‌ای در این patch تولید نشده و هیچ build/test واقعی روی سورس محصول انجام نشده است.
