# ممیزی آمادگی مخزن و قرارداد شواهد

## 1. وضعیت ورودی بسته
در زمان تدوین این patch، اسناد محصول/طراحی در دسترس بوده‌اند. checkout کامل سورس برنامه (کد UI، project/solution واقعی، migration اجرایی، تست‌های buildپذیر و installer) در دسترس این مرحله نبوده است. بنابراین این سند «ممیزی مستندات و آمادگی» است، نه نتیجه ممیزی سورس اجرایی.

## 2. مشاهدات مستنداتی
- README پیشین به `docs/10-master-ai-coding-directive.md` اشاره می‌کرد؛ در مجموعه مستندات پایه‌ی بررسی‌شده این فایل در آن مسیر موجود نبود، در حالی که یک دستور مادر جداگانه وجود داشت. این patch دستور را در مسیر اعلام‌شده می‌آورد.
- نقشه فازهای اصلی 0 تا 9 برای کشف/سازگاری، پایه، داده‌های اصلی، سورتینگ، انبار/ارسال، فاکتور، صافی، حسابداری، UI/گزارش و سخت‌سازی تعریف شده بود. این patch آن را به پرامپت‌های مستقل و گیت‌های شواهدی گسترش می‌دهد.
- import/export، تطبیق اشخاص و چاپ قالب‌پذیر، و بانک/چک به‌عنوان اسناد توسعه‌ای تکمیلی در بسته گنجانده شده‌اند.
- وجود اسناد به معنی وجود کد متناظر، build موفق، تست موفق، آفلاین بودن عملی یا Windows 7 compatibility نیست.

## 3. وضعیت تست و build
- Build: `NOT RUN` در مرحله تدوین این patch؛ سورس اجرایی در دسترس نبوده است.
- Unit/Integration/E2E: `NOT RUN`.
- Offline runtime: `NOT VERIFIED`.
- Windows 7 SP1 x64: `NOT VERIFIED`.
- Installer/upgrade/restore: `NOT VERIFIED`.

## 4. اقدام لازم روی مخزن اصلی
1. patch مستندات را بازبینی و به مخزن اضافه کنید.
2. پرامپت `00-repository-audit.md` را روی checkout واقعی اجرا کنید.
3. خروجی audit را با این سند مقایسه کنید و هر نتیجه مربوط به کد را فقط بر اساس فایل و فرمان واقعی ثبت کنید.
4. اگر repo اصلی شاخه/نام/پوشه دیگری دارد، مسیر فایل‌ها را با قرارداد فعلی تطبیق دهید، نه اینکه فایل‌ها را کورکورانه overwrite کنید.
5. فاز سازگاری/عمودی را پیش از پیاده‌سازی وسیع انجام دهید.

## 5. عبارت‌های وضعیت استاندارد
- `IMPLEMENTED`: پیاده‌سازی در کد وجود دارد.
- `TESTED`: تست مرتبط اجرا شده و PASS است؛ نتیجه/شاهد ثبت شده.
- `NOT RUN`: اجرا نشده.
- `NOT VERIFIED`: فرض/نتیجه هنوز شواهد کافی ندارد.
- `BLOCKED`: به دلیل مشخصی امکان اجرا یا تصمیم‌گیری وجود ندارد.
- `PARTIAL`: قسمتی انجام شده اما معیار پذیرش کامل پاس نشده.
