# فاز 23 — کارایی، پایداری و ممیزی آفلاین

**شناسه:** SORTING-OS-P23  
**محدوده:** کار روزانه باید قابل پیش‌بینی باشد؛ نه فقط در دیتاست کوچک.

## دستور قابل کپی برای عامل برنامه‌نویس

تو در حال کار روی مخزن واقعی SORTING OS هستی. دستور مادر `MASTER_PROMPT.md` و فایل‌های مرجع `PROJECT_SPEC.md` و مستندات مرتبط را رعایت کن. **فقط همین مرحله را اجرا کن؛ فازهای بعد را آغاز نکن.**

### هدف
عملکرد و دوام عملیات را با حجم نماینده و شبکه قطع‌شده بررسی کن.

### کارهای دقیق
- سناریوهای واقع‌بینانه حجم داده (تعداد اشخاص، محموله، خطوط گردش موجودی، فاکتور، bank rows و گزارش‌ها) را با داده synthetic برچسب‌دار بساز.
- زمان startup، جست‌وجو، ثبت سند، بازکردن پرونده شخص، گزارش دوره‌ای، preview چاپ، import batch و backup/restore را اندازه بگیر؛ آستانه‌ها را با سخت‌افزار هدف و تصمیم صاحب محصول تعیین کن، نه حدس.
- query plan/index، تعداد round trip، N+1، قفل طولانی، حافظه و رشد log را بررسی کن.
- crash/restart، disk full، read-only folder، database corruption simulation، backup ناقص، file lock، همزمانی و shutdown حین عملیات را آزمایش کن.
- آفلاین را با قطع فیزیکی/مسدودسازی شبکه ثابت کن؛ dependency scanner فقط مکمل است. جست‌وجوی DNS/HTTP، telemetry، CDN، font fetch، licensing و auto-update انجام بده.
- اگر API قیمت اختیاری است، پیش‌فرض خاموش، timeout کوتاه، عدم مسدودشدن عملیات پایه و نبود فراخوانی در حالت خاموش را تست کن.
- Windows 7 را فقط روی VM/سخت‌افزار واقعی هدف آزمون کن؛ نتیجه مدرن Windows را جایگزین آن نکن.

### معیار پذیرش
baseline اندازه‌گیری‌شده، محدودیت‌ها، پروفایل‌های مورد استفاده، شواهد تست آفلاین و نتایج جداگانه هر سیستم‌عامل ارائه شود.


## قرارداد مشترک اجرا (الزامی)

این پرامپت را در مخزن واقعی اجرا کن، نه بر اساس حدس. قبل از تغییر، دستور مادر و اسناد مربوط را بخوان؛ `git status`، branch و commit را ثبت کن؛ تغییرات کاربر را دست‌نخورده نگه دار. محدوده این پرامپت تنها محدوده مجاز همین نوبت است. قبل از پیاده‌سازی، فایل‌های محتمل، وابستگی‌ها، خطر داده، اثر UI/مجوز/گزارش، migration و تست را مشخص کن. اگر یکی از قواعد تجاری لازم نامشخص است، به‌جای حدس‌زدن تصمیم باز ثبت کن و بخش وابسته را اجرا نکن. پس از تغییر، build و تست واقعی اجرا کن، diff را مرور کن، اسناد را به‌روز کن و گزارش انتهایی قالب دستور مادر را بده. موفقیت build یا تست، سازگاری Windows 7 یا آفلاین‌بودن را بدون شواهد ادعا نکن. در این نوبت به پرامپت بعدی نرو.
