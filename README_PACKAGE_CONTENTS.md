# فهرست بسته نهایی SORTING OS

- `README.md`, `PROJECT_SPEC.md`, `CONTRIBUTING.md`: نقطه ورود مخزن.
- `MASTER_PROMPT_FOR_AGENT_FA.md`: قانون مادر عامل کدنویس.
- `PROMPT_INDEX_00_TO_35_FA.md`, `prompts/`, `ALL_PROMPTS_00_TO_35_FULL_FA.md`: توالی کامل ۳۶ مرحله.
- `docs/agent-system/UPLOAD_FIRST_ORDER_FA.md`: ترتیب دقیق بارگذاری مراجع پیش از Prompt 00.
- `docs/financial/`: مشخصات حسابداری، واحد ریال/تومان، کاتالوگ گزارش و سناریوهای پذیرش.
- `docs/`: قواعد دامنه/معماری، workflow، UI/UX، بانک، پشتیبان‌گیری، release، تست، تصمیم‌نامه و examples.
- `contracts/`: وضعیت پیاده‌سازی، گیت‌های انتشار، گزارش عامل، traceability و invariants.
- `desktop/`: برنامه اجرایی از سورس، هسته حسابداری، تست‌ها و scripts.
- `reference-inputs/`: اسناد اصلی قبلی بدون حذف برای حفظ تاریخچه و ردیابی تعارض‌ها.
- `repository-patch/`: مواد کمکی/patch از نسخه‌های قبلی؛ قبل از انتقال آن‌ها، با فایل‌های canonical جاری merge و مقایسه شوند.
- `MANIFEST.json`, `SHA256SUMS.txt`: manifest و checksumهای تولیدشده برای اعتبارسنجی فایل‌ها.

فایل‌های Excel، bank statement، دیتابیس عملیاتی و داده واقعی اشخاص عمداً وارد این بسته نشده‌اند.
