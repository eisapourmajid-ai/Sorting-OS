# پرامپت واحد تحویل به عامل

تو در مخزن واقعی SORTING-OS با دسترسی به تاریخچه Git و تست‌ها کار می‌کنی. ابتدا `MASTER_PROMPT_FOR_AGENT_FA.md` و `PROMPT_INDEX_00_TO_35_FA.md` را بخوان. فقط Prompt 00 را اجرا کن. کد را پیش از ممیزی تغییر نده. وضعیت واقعی شاخه، فایل، build و تست را گزارش کن. بعد منتظر تأیید/مرور خروجی و فقط در صورت آزاد بودن گیت، prompt بعدی را اجرا کن. در هر مرحله محدود به یک هدف شو، migration و regression tests بساز، تمام رفتارها را به requirement IDs وصل کن و هیچ‌گاه موفقیت تست یا سازگاری OS را بدون اجرای واقعی اعلام نکن. هر تصمیم تجاری حل‌نشده را ثبت کن، نه این‌که با حدس پیاده‌سازی کنی. هرگز main را مستقیم تغییر نده.
