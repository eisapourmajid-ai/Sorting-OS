# تصمیم‌های باز — SORTING OS

این فایل خلاصهٔ «تصمیم‌های حل‌نشده» است که طبق قاعدهٔ `MASTER_PROMPT_FOR_AGENT_FA.md` و
`docs/decision-log.md` نباید با فرض فنی خودسرانه به قانون محصول تبدیل شوند. هر قابلیت وابسته تا
روشن‌شدن تصمیم در وضعیت `BLOCKED` / feature-flag می‌ماند.

مرجع کامل: `docs/decision-log.md` (DEC-001..DEC-016، ADR-001..ADR-005).

## قواعد حاکم بر این فهرست

1. تا وقتی تصمیم `Accepted` نشده، هیچ عدد «رایج» (درصد صافی، نرخ کمیسیون، تلورانس وزن، روش
   ارزش‌گذاری) به‌عنوان قانون وارد محصول نمی‌شود.
2. قابلیت وابسته به تصمیم باز، یا `BLOCKED` می‌ماند یا صریحاً «موقت/پیش‌فرض» برچسب می‌خورد
   (مثل FIFO صافی و درصد پیش‌فرض موتور صافی).
3. هر تصمیم باید شواهد، مالک، اثر migration و تاریخ داشته باشد.
4. «پیاده‌سازی شد» به‌معنای «تأیید تجاری شد» نیست؛ این دو در گزارش‌ها جداگانه درج می‌شوند.
