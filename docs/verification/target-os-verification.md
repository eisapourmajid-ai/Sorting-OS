# شواهد اجرای آفلاین و وضعیت تأیید روی سیستم‌عامل هدف (Prompt 27)

- تاریخ اجرا: 2026-10-19
- محیط اجرا: Linux (sandbox), Python 3.11.2, SQLite 3.40.1
- وضعیت کلی: **PARTIAL** — آفلاین‌بودن با آزمون خودکار اثبات شده؛ **Windows 7 SP1 x64 و نصب‌کننده آزموده نشده‌اند**.

## ۱) آفلاین‌بودن — شواهد اجرایی

| آزمون | دستور | خروجی واقعی |
|---|---|---|
| تحلیل ایستای کد: هیچ کلاینت شبکه | `python -m unittest tests.test_offline.SourceScanTests -v` | PASS — هیچ `import socket/urllib/requests/...` در `desktop/sorting_os/` |
| تحلیل ایستای کد: بدون telemetry/auto-update | همان تست | PASS |
| بارگذاری بسته بدون ماژول شبکه | subprocess تازه + بررسی `sys.modules` | PASS — `socket` بارگذاری نمی‌شود (به همین دلیل handler چرخشی لاگ به‌صورت محلی پیاده شده است) |
| جریان کامل کسب‌وکار با مسدودسازی `socket.socket` | `tests/test_offline.py:BlockedNetworkTests` | PASS — محموله → سورتینگ → فاکتور → posting → گزارش، همه بدون شبکه |
| پشتیبان‌گیری بدون شبکه | همان تست | PASS |

هیچ مسیر runtime به CDN، login ابری، telemetry، auto-update یا سرویس بیرونی وصل نیست. جست‌وجوی
شبکه در کل بستهٔ `desktop/sorting_os/` انجام شده و نتیجه در جدول بالا آمده است.

## ۲) چه چیزی «NOT RUN / NOT VERIFIED» است

| قلم | وضعیت | دلیل |
|---|---|---|
| اجرای رابط گرافیکی (Tkinter) | `NOT RUN` | tkinter در این محیط نصب نیست؛ هیچ پنجره‌ای باز نشده و هیچ تصویری ثبت نشده است |
| Windows 7 SP1 x64 | `NOT VERIFIED ON TARGET OS` | سیستم‌عامل هدف در دسترس نیست |
| ساخت EXE با PyInstaller | `NOT RUN` | PyInstaller نصب نیست |
| ساخت نصب‌کننده (NSIS/InnoSetup) | `NOT RUN` | ابزار نصب‌کننده در دسترس نیست |
| چاپ روی پرینتر واقعی | `NOT RUN` | پرینتر/درایور در دسترس نیست (منطق چاپ متنی آزمون شده) |
| مهاجرت دادهٔ واقعی مشتری | `NOT RUN` | دادهٔ واقعی در دسترس نیست و نباید در مخزن باشد |

## ۳) چک‌لیست اجباری روی سیستم‌عامل هدف (Windows 7 SP1 x64)

این چک‌لیست باید روی ماشین هدف اجرا و نتیجهٔ واقعی آن در `reports/` ثبت شود. تا آن زمان هیچ
ادعای «سازگار با ویندوز ۷» مجاز نیست.

1. **نصب تمیز**
   - [ ] Python 3.8.10 x64 نصب و `python -c "import tkinter, sqlite3"` موفق.
   - [ ] اجرای `desktop/run_windows.bat` بدون خطای کنسول.
2. **پایگاه داده**
   - [ ] ایجاد پایگاه داده تازه در مسیر داده کاربر و اجرای migration.
   - [ ] ارتقای یک پایگاه نسخهٔ ۱ (ساخته‌شده با نسخهٔ قبلی) و حفظ داده.
3. **آزمون‌ها**
   - [ ] `python -m unittest discover -s tests -v` روی همان ماشین (ثبت زمان و تعداد تست).
   - [ ] اجرای suite روی Python 3.8 (سازگاری نسخهٔ پایین).
4. **رابط کاربری**
   - [ ] باز شدن پوسته و جابه‌جایی بین همهٔ صفحات.
   - [ ] نمایش فارسی/RTL و درستی جداسازی اعداد و کدهای لاتین.
   - [ ] سوییچ تم روشن/تیره و ماندگاری انتخاب پس از راه‌اندازی مجدد.
   - [ ] بستن پنجره با فرم تغییرکرده ⇒ هشدار «تغییرات ذخیره‌نشده».
5. **چاپ**
   - [ ] پیش‌نمایش چاپ فاکتور/توزین/صافی با درج واحد مبلغ.
   - [ ] چاپ روی پرینتر A4 و پرینتر حرارتی.
6. **بسته‌بندی**
   - [ ] ساخت EXE با PyInstaller و پرچم سازگاری W7.
   - [ ] اجرای EXE روی ماشین **بدون** Python نصب‌شده.
   - [ ] بررسی رفتار در مسیر دارای فارسی/فاصله و نام کاربر فارسی.
7. **کارایی**
   - [ ] اندازه‌گیری زمان پاسخ گزارش و posting روی همان ماشین و ثبت عدد واقعی.
8. **پشتیبان**
   - [ ] backup ⇒ بازیابی ⇒ تطبیق با نسخهٔ اصلی.
   - [ ] اجرای برنامه از مسیر شبکه/USB و اطمینان از رفتار مسیر داده.

## ۴) دستورهای آمادهٔ اجرا برای اپراتور

```bat
cd desktop
python -m unittest discover -s tests -v
python -m sorting_os --doctor
python -m sorting_os --init-db
```

معیار پذیرش این مرحله: بندهای ۱ تا ۸ با «✓» و ثبت خروجی واقعی. وضعیت فعلی: **۰ از ۸ بند
اجرا شده** (محیط هدف در دسترس نبود) ⇒ این مرحله `NOT VERIFIED ON TARGET OS` باقی می‌ماند.
