# معماری آفلاین و سازگاری Windows 7

## 1. تصمیم کلیدی

Windows 7 SP1 x64 حداقل هدف درخواست‌شده است، اما سیستم‌عامل خارج از پشتیبانی عمومی است. مایکروسافت پایان پشتیبانی Windows 7 را 14 ژانویه 2020 اعلام کرده است. بنابراین دو موضوع باید جدا سنجیده شوند:

1. **Compatibility:** آیا binary و وابستگی‌ها در سیستم‌عامل اجرا می‌شوند؟
2. **Security support:** آیا سیستم‌عامل هنوز به‌روزرسانی امنیتی عمومی دریافت می‌کند؟

ممکن است پاسخ اول با آزمایش مثبت باشد، در حالی که دوم منفی است.

## 2. نامزد تکنولوژی اولیه

برای بررسی اولیه، C# + WPF + .NET Framework 4.8 + SQLite قابل ارزیابی است. مستندات Microsoft Windows 7 SP1 را در جدول سیستم‌عامل‌های سازگار .NET Framework 4.8 ذکر می‌کنند؛ با این وجود، این فقط یک داده اولیه است و آزمون کل stack الزامی باقی می‌ماند.

هیچ نسخه‌ای از کتابخانه‌های جانبی تا زمان آزمون با برچسب «سازگار قطعی» منتشر نشود.

## 3. Offline Acceptance Checklist

### زمان اجرا

- [ ] با خاموش‌بودن Wi-Fi/Ethernet برنامه باز می‌شود.
- [ ] ورود کاربر محلی کار می‌کند.
- [ ] داشبورد باز می‌شود.
- [ ] اشخاص/باسکول/محموله/انبار/فاکتور/صافی ثبت می‌شوند.
- [ ] گزارش و چاپ کار می‌کند.
- [ ] پشتیبان‌گیری و بازیابی کار می‌کند.
- [ ] فونت، آیکون، تصویر و قالب گزارش از فایل محلی بارگذاری می‌شوند.
- [ ] هیچ telemetry یا analytics اجرا نمی‌شود.
- [ ] هیچ مجوز آنلاین لازم نیست.
- [ ] API قیمت در حالت پیش‌فرض خاموش است.
- [ ] خاموش‌بودن شبکه باعث timeoutهای طولانی در UI نمی‌شود.

### بسته‌بندی

- [ ] تمام dependencyهای ضروری در installer یا بسته‌های همراه وجود دارند.
- [ ] پیش‌نیاز runtime پیش از نصب بررسی می‌شود.
- [ ] نصب‌کننده در ماشین تمیز و بدون اینترنت آزمایش می‌شود.
- [ ] نصب نیازمند دانلود خودکار نیست.
- [ ] نسخه‌ها و checksum بسته‌های انتشار ثبت می‌شوند.
- [ ] فایل‌های بومی 32/64 بیت با نسخه برنامه تطبیق دارند.

## 4. مراحل گیت سازگاری Windows 7

### Gate W7-0 — ثبت محیط

مشخصات محیط را ثبت کن:
- edition و service pack؛
- x64؛
- patch level موجود؛
- نسخه runtime؛
- چاپگر و درایور؛
- DPI و رزولوشن؛
- سطح دسترسی نصب‌کننده.

### Gate W7-1 — نمونه Hello/RTL

یک اپلیکیشن کوچک باید پنجره WPF، فونت محلی، متن فارسی، یک جدول، یک نمودار ساده محلی و چاپ ابتدایی را اجرا کند.

### Gate W7-2 — پایگاه داده

ساخت پایگاه داده، migration، insert/update/read، transaction rollback، قفل و بازیابی بررسی شوند.

### Gate W7-3 — نصب آفلاین

یک VM تمیز با شبکه خاموش تهیه شود. نصب، اولین اجرا، ایجاد داده و راه‌اندازی مجدد انجام شود.

### Gate W7-4 — سناریوی عملیات

حداقل یک مسیر کامل از باسکول تا انبار و گزارش چاپی اجرا شود.

### Gate W7-5 — ثبت نتیجه

گزارش پاس/فیل، مشکل‌ها، workaroundها و checksum نسخه آزموده‌شده ذخیره شوند. سازگاری فقط برای همین ترکیب دقیق از نسخه برنامه و محیط قابل ادعا است.

## 5. SQLite: استفاده محلی و مرز شبکه

SQLite برای پایگاه داده تعبیه‌شده و محلی مناسب است. فایل DB را روی رایانه محلی نگه دارید. اگر در آینده چند سیستم باید هم‌زمان به داده مشترک بنویسند، فایل SQLite را مستقیم از share شبکه باز نکنید. مستندات SQLite درباره وابستگی قفل‌گذاری به فایل‌سیستم شبکه و ریسک خرابی هشدار می‌دهد: https://www.sqlite.org/useovernet.html

معماری چندرایانه‌ای پیشنهادی: کلاینت‌ها از یک سرویس کاربردی در LAN استفاده کنند و سرویس مالک دسترسی به پایگاه داده باشد. انتخاب دیتابیس client/server در فاز جداگانه و بر اساس هم‌زمانی، نگهداری و پشتیبانی انتخاب شود.

## 6. مدیریت نسخه وابستگی‌ها

برای هر dependency این اطلاعات ثبت شوند:
- نام؛
- نسخه دقیق؛
- مجوز؛
- منبع دریافت؛
- معماری باینری؛
- حداقل سیستم‌عامل مستند؛
- مسیر بسته‌بندی؛
- نتیجه تست Windows 7؛
- ریسک امنیتی شناخته‌شده.

از `latest`، دریافت زمان اجرا و دانلود پویا پرهیز شود. به‌روزرسانی وابستگی باید PR و آزمون مجدد داشته باشد.

## 7. شبکه اختیاری قیمت

- پیش‌فرض: غیرفعال.
- API key به‌صورت متن ساده داخل سورس کد ذخیره نشود.
- شکست API به عملکرد محلی آسیب نزند.
- تاریخ/ساعت دریافت و نام منبع ذخیره شود.
- مقدار قدیمی با برچسب «آخرین مقدار ذخیره‌شده در تاریخ ...» نمایش داده شود.
- کاربر بتواند بدون پاک‌شدن قیمت قبلی، قیمت جدید دستی ثبت کند.
- timeout کوتاه و غیرمسدودکننده UI باشد.
- هیچ محاسبه حسابداری قطعی به پاسخ زنده API وابسته نباشد.

## 8. امنیت محیط Windows 7

از آنجا که Windows 7 خارج از پشتیبانی عمومی است:
- استفاده از آن برای داده مالی حساس ریسک دارد؛
- دسترسی اینترنتی سیستم در صورت امکان محدود شود؛
- حساب کاربری روزمره حداقل مجوز لازم را داشته باشد؛
- نسخه‌های پشتیبان مستقل و آزمون بازیابی نگهداری شوند؛
- فایل‌های اجرایی از مسیر معتبر دریافت و checksum بررسی شوند؛
- برنامه در صورت امکان روی رایانه/شبکه محدودشده اجرا شود.

نرم‌افزار آفلاین نمی‌تواند تمام ریسک‌های امنیتی سیستم‌عامل قدیمی را حذف کند.
