# SORTING OS — هسته دسکتاپ آفلاین (MVP)

**وضعیت:** کد اجرایی پایه برای شروع بهره‌برداری آزمایشی؛ نه نسخه نهایی حسابداری و نه نسخه تأییدشده Windows 7.

## قابلیت‌های پیاده‌سازی‌شده

- برنامه دسکتاپ فارسی با رابط راست‌چین نسبی، داشبورد و پیمایش بین بخش‌ها.
- ذخیره‌سازی محلی SQLite؛ داده‌ها در `%LOCALAPPDATA%\SORTING_OS\sorting_os.sqlite3` نگهداری می‌شوند.
- پرونده اشخاص/صاحبان کالا با شناسه داخلی، نقش، تلفن، کد ملی، نشانی و کنترل تکرار کد ملی.
- ثبت محموله ورودی متصل به مالک کالا.
- ثبت قبض باسکول با وزن ناخالص، وزن خالی و محاسبه وزن خالص؛ منع ناخالص کمتر از خالی.
- ثبت فاکتور پایه متصل به شخص و در صورت نیاز به محموله، با وضعیت پیش‌نویس/قطعی.
- خروجی CSV با UTF-8 BOM برای اشخاص، محموله‌ها، باسکول و فاکتورها.
- پیش‌نمایش ورود CSV اشخاص؛ ردیف‌های مشابه یا دارای کد ملی تکراری به‌طور خودکار ادغام نمی‌شوند و برای بررسی کنار گذاشته می‌شوند.
- نسخه پشتیبان SQLite و ثبت سوابق عملیات پایه.
- تست‌های واحد برای قیود داده و قواعد اصلی.

## اجرا

1. Python 3.8 x64 را نصب کنید. برای مسیر Windows 7، از محیط پایتونی استفاده کنید که روی همان سیستم‌عامل پشتیبانی و آزمایش شده باشد.
2. روی `run_windows.bat` دوبار کلیک کنید یا اجرا کنید: `python main.py`.
3. برنامه بدون اینترنت و بدون بسته‌های خارجی اجرا می‌شود؛ Tkinter و SQLite از کتابخانه استاندارد پایتون استفاده می‌شوند.

## آزمون‌ها

از مسیر پوشه پروژه اجرا کنید:

```bat
python -m unittest discover -s tests -v
```

## ساخت EXE

`build_windows.bat` مسیر ساخت PyInstaller را نشان می‌دهد. **فایل EXE باید روی ویندوز هدف ساخته و آزمایش شود**؛ اجرای build در این تحویل انجام نشده و سازگاری Windows 7 SP1 x64 هنوز تأیید نشده است.

## حسابداری و گزارش مالی پایه (افزوده‌شده در این بسته)

- `accounting_core.py` دفترکل دوبل محلی با ذخیره integer ریال و تبدیل دقیق ریال/تومان دارد.
- صفحه «حسابداری و گزارش مالی» ثبت سند دوبل متوازن و نمایش تراز آزمایشی، ترازنامه، سود و زیان، جریان وجوه نقد مدیریتی و نسبت‌های پایه را فراهم می‌کند.
- سند نامتوازن و source posting تکراری رد می‌شود؛ اصلاح از طریق سند برگشت قابل پیگیری است.
- گزارش‌ها فقط از خطوط دفترکل قطعی می‌خوانند؛ فاکتورهای قدیمی به‌طور خودکار در گزارش مالی محسوب نمی‌شوند.
- تاریخ ورودی هسته فعلی ISO میلادی است. تقویم شمسی، اتصال posting به تمام عملیات، دوره مالی و کدینگ نهایی هنوز نیازمند تکمیل است. گزارش جریان نقدی و بعضی نسبت‌ها تا بازبینی حسابدار، مدیریتی/پایه هستند.
